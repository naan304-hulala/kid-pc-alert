# kid-pc-alert

아이 컴퓨터가 켜지고 꺼질 때 부모님 카카오톡("나와의 채팅")으로 시각과 사용 시간을 알려주는 Windows 11 프로그램이에요.
화면에 아무것도 뜨지 않는 Windows 서비스로 동작해요.

기획서: https://claude.ai/artifact/5rNvV5PZ2avqkiHbiRMj8T

## 알려주는 것

| 언제 | 메시지 예시 |
| --- | --- |
| 켜짐, 절전 해제 | `[큰애 PC] 켜짐 (부팅)` + 시각, 계정 |
| 꺼짐, 절전 진입 | `[큰애 PC] 꺼짐 (종료)` + 시각, 이번 사용, 오늘 총 사용 |
| 23:20 이후 사용 | 메시지 앞에 `[늦은 시간]`, 켜져 있으면 밤마다 한 번 "아직 사용 중" |
| 낯선 계정 로그인, 새 계정 생성 | `[주의] ...` |
| 감지 프로그램 중지 | `[주의] 감지 프로그램이 중지됐어요` |
| 강제 종료(전원 버튼 길게) | 다음에 켜질 때 "비정상 종료, 마지막 확인 시각 기준"으로 알림 |

인터넷이 끊겨 있으면 `C:\ProgramData\KidPcAlert\outbox.json`에 모아 뒀다가 연결되면 보내요.

## 설치 방법

1. 카카오 개발자 사이트에서 앱을 만들고 **REST API 키**를 준비해요.
   - 카카오 로그인 활성화, Redirect URI `http://localhost:8765/callback`
   - 동의항목에서 "카카오톡 메시지 전송" 사용
2. GitHub 저장소의 **Actions → build → 가장 최근 실행 → Artifacts → KidPcAlert**를 내려받아 압축을 풀어요.
3. 아이 컴퓨터에서 `install.cmd`를 더블클릭하고 "예"(관리자 허용)를 눌러요.
4. 검은 창의 질문에 답하고, 브라우저에서 부모님 카카오 계정으로 로그인해요.
5. 휴대폰에 "설정 완료" 카톡이 오면 끝이에요.

제거는 같은 폴더의 `uninstall.cmd`를 실행해요.

## 꼭 지킬 것

- 아이 계정은 **표준 사용자**여야 해요. 관리자면 프로그램을 끄거나 지울 수 있어요.
- 설치하면 Windows "빠른 시작"이 꺼져요. 그래야 켜짐/꺼짐이 정확히 잡혀요.

## 구조

| 파일 | 하는 일 |
| --- | --- |
| `AlertService.cs` | 숨은 경비원. 전원, 절전, 로그인 신호를 받아요 |
| `UsageTracker.cs` | 켜진 시각, 사용 시간 계산, 메시지 문장 만들기 |
| `Notifier.cs` | 기록장(outbox)에 적고 순서대로 보내기 |
| `KakaoClient.cs` | 카카오 "나에게 보내기", 토큰 자동 갱신 |
| `Setup.cs` | 설치 때 한 번 쓰는 설정 창, 카카오 로그인 |
